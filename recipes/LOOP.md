# לולאת מתכונים יומית — הוראות עבודה

כל ריצה מוסיפה **50 מתכונים חדשים** כקובץ מקור אחד `recipes/src/NNN.txt` (המספר הבא ברצף).

## כללים (חובה)
1. **כשרות**: אין חזיר/פירות ים/דגים ללא קשקשים; אין בשר עם חלב; אין בשר עם דגים. כל מתכון מסומן פרווה / חלבי / בשרי לפי המרכיבים. תחליפים פרווה (חלב קוקוס, שמנת צמחית, מרגרינה) מותרים במנות בשריות. הכבד נצלה להכשרה — לציין בתגית.
2. **מקוריות**: לא מעתיקים טקסט מאתרים. כל מתכון נכתב מחדש במילים שלנו, על בסיס מנות מוכרות ומבוססות (מטבח ישראלי, יהודי־עדתי, ים־תיכוני, אסייתי, אירופי, אפייה). כמויות וזמנים סבירים ובדוקים מול הידע המקובל.
3. **גיוון**: לפחות 10 ארוחות בוקר/קלות, 15 עיקריות, 10 תוספות/סלטים/מרקים, 8 מאפים/קינוחים, השאר חופשי. לפחות 20 פרווה, 10 חלבי, 10 בשרי. רמות קושי מעורבות.
4. **בלי כפילויות**: לבדוק מול `recipes/data/index.json` (שדה n). ה-build נכשל על שם קיים.
5. **ניסוח שעובר את הבודק**: מוצר צמחי נכתב בשמו המלא בכל מקום, גם בשלבים ("שניצל תירס", לא "השניצל"). עלים ירוקים (חסה, פטרוזיליה, כוסברה, נענע, כרוב) → תגית "בדיקת חרקים". יין / מיץ ענבים → תגית "בהכשר".
6. **פורמט**: ראו ראש הקובץ `tools/build-recipes.mjs` ודוגמאות ב-`recipes/src/001.txt`. יחידות מותרות: הרשימה `UNITS` בכלי.

## תהליך
```
node tools/build-recipes.mjs        # חייב ✓; מתקנים כל ✗ ומריצים שוב
node tests/smart.test.mjs
git add recipes && git commit -m "recipes: +50 (batch NNN)" && git push origin HEAD:main
```
לעדכן שורה ב-`recipes/data/LOG.md`. חזרה אחורה: `git revert` לקומיט של הבאץ'.

## גבולות
- כשקובץ `index.json` עובר 1.5MB — לעצור ולדווח (צריך לפצל את האינדקס לפי קטגוריה לפני שממשיכים).
- נתונים בלבד: הלולאה לא נוגעת בקוד האפליקציה.
